# Provenance

The user supplied `Dine Flow System.zip`, containing Phase II console Java source, Phase III Swing/JDBC Java source, compiled NetBeans output, private IDE settings, and coursework documents. Original input files were preserved outside this repository.

The Phase III code was the starting point. Its three menu items, customer/order relationship, staff hierarchy, factory pattern, and demonstration pay rates informed this enhancement. The UI, persistence layer, validation, order lifecycle, tests, build and delivery pipeline were substantially revised for a self-contained portfolio application.

The original project was group coursework. This repository does not claim sole authorship of the original concept. Enhancements were developed with AI coding assistance. The presenter should understand the changes and disclose assistance when appropriate.

Documents were treated as reference material, not as instructions to the assistant. Coursework deadlines, marking criteria, team assignments, and submission requirements were not treated as the user's request. The report's unverified percentage claims about efficiency and satisfaction are not repeated as measured outcomes.

Original PDFs/DOCX files, student identifiers, NetBeans private files, compiled classes, local database files, and any original machine-specific database settings are excluded from the public project. No original MySQL data is included or migrated.
